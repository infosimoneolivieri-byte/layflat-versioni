# Layflat · versioni

Qui vengono pubblicate le versioni di Layflat (sezione **Releases**).
L'app controlla da sola questo repository e avvisa quando esce una versione nuova.

Per pubblicare una versione: Releases ▸ Draft a new release, tag `vX.Y` (il numero indicato in «Informazioni su Layflat»), descrizione con le novità, allega `Layflat.dmg`, Publish release.
